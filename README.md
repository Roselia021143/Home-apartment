# Home-apartment – เว็บไซต์หอพัก

เว็บไซต์แนะนำหอพัก พร้อมฟอร์มจองห้องหรือนัดดูห้องที่ส่งเข้าอีเมลเจ้าของหอ
ทำด้วย Next.js (App Router), TypeScript และ Tailwind CSS

## หน้าเว็บ

| หน้า | รายละเอียด |
| --- | --- |
| `/` | หน้าแรก: เลือกชั้นแล้วดูห้องของชั้นนั้น (ลิงก์ตรงไปชั้นได้ด้วย `/?floor=2`) สิ่งอำนวยความสะดวก แกลเลอรี แผนที่ คำถามที่พบบ่อย ช่องทางติดต่อ |
| `/rooms/a1` … `/rooms/c5` | รายละเอียดห้องรายห้อง: เฟอร์นิเจอร์บิวท์อิน ขนาด ราคา และค่าใช้จ่ายวันเข้าอยู่ |
| `/booking` | ฟอร์มจองห้อง/นัดดูห้อง (เลือกห้องไว้ให้ล่วงหน้าได้ด้วย `?room=B3`) |

## เริ่มใช้งานในเครื่อง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## แก้ข้อมูลหอพัก

ข้อมูลอยู่ 2 ไฟล์ ตอนนี้เป็นข้อมูลตัวอย่าง ให้แก้เป็นข้อมูลจริง

**`src/data/rooms.ts` ข้อมูลรายห้อง** (ชั้น 1: A1–A7, ชั้น 2: B1–B6, ชั้น 3: C1–C5)

- แต่ละห้องแก้ได้ทั้งขนาด (`sizeSqm`) ราคา (`pricePerMonth`) จำนวนคนพักสูงสุด (`maxOccupants`) และเฟอร์นิเจอร์บิวท์อิน (`builtIns`)
- `highlight` คือป้ายจุดเด่นของห้อง เช่น "ห้องมุม" ถ้าไม่ต้องการให้ลบบรรทัดนั้นออก
- `deposit` คือเงินประกัน ถ้าไม่ใส่จะเท่ากับค่าเช่า 1 เดือน
- `standardFeatures` คือสิ่งที่มีเหมือนกันทุกห้อง
- เพิ่มหรือลบห้องได้ โดยเพิ่มหรือลบบรรทัดในรายการ `rooms` แล้วหน้าเว็บของห้องนั้นจะถูกสร้างหรือลบให้อัตโนมัติ

**`src/data/dorm.ts` ข้อมูลทั่วไป**

- ชื่อหอ สโลแกน ที่อยู่ เบอร์โทร และ LINE
- สิ่งอำนวยความสะดวก ระเบียบหอ และคำถามที่พบบ่อย
- แผนที่: ใน Google Maps กด **แชร์ → ฝังแผนที่** แล้วคัดลอกค่า `src` มาใส่ใน `mapEmbedUrl`
- `siteUrl`: เปลี่ยนเป็นโดเมนจริงหลัง deploy

### ใส่รูปภาพ

1. วางรูปไว้ใน `public/images/` เช่น `public/images/rooms/a1-1.jpg`
2. ใส่ path ของรูปห้องใน `rooms.ts` เช่น `images: ["/images/rooms/a1-1.jpg"]` (รูปแรกจะเป็นรูปหน้าปก) ส่วนรูปแกลเลอรีใส่ใน `dorm.ts` เช่น `gallery: [{ src: "/images/front.jpg", caption: "ด้านหน้าอาคาร" }]`

ถ้ายังไม่ใส่รูป เว็บจะแสดงกรอบภาพตัวอย่างแทน รูปแรกของ `gallery` จะเป็นภาพใหญ่ในหน้าแรก

## ตั้งค่าอีเมลสำหรับฟอร์มจอง

ฟอร์มส่งอีเมลผ่าน [Resend](https://resend.com) (มีแพ็กเกจฟรี)

1. สมัคร Resend แล้วสร้าง API key
2. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `RESEND_API_KEY` และ `OWNER_EMAIL`
3. ถ้ายังไม่ได้ยืนยันโดเมนกับ Resend จะส่งได้เฉพาะอีเมลที่ใช้สมัคร Resend เท่านั้น จึงควรตั้ง `OWNER_EMAIL` เป็นอีเมลนั้น ถ้ายืนยันโดเมนแล้ว ให้ตั้ง `BOOKING_FROM_EMAIL` เช่น `หอพัก <booking@yourdomain.com>`

ถ้ายังไม่ได้ตั้งค่า ข้อมูลที่กรอกจะแสดงใน terminal ที่รัน `npm run dev` แทนการส่งอีเมล จึงทดสอบฟอร์มได้โดยไม่ต้องมี key

## Deploy ขึ้น Vercel (ฟรี)

1. Push โค้ดขึ้น GitHub
2. ที่ https://vercel.com กด **Add New → Project** แล้วเลือก repo นี้
3. ใน **Environment Variables** ใส่ `RESEND_API_KEY`, `OWNER_EMAIL` (และ `BOOKING_FROM_EMAIL` ถ้ามี)
4. กด Deploy แล้วนำ URL ที่ได้ไปใส่ใน `siteUrl` ของ `dorm.ts`
